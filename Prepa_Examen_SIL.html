Fiches express (à mémoriser)

Numération & conversions

  • Binaire→décimal : somme des puissances de 2. Ex. 111001 = 32+16+8+1 = 57.
  • Décimal→binaire : divisions successives par 2, on lit les restes de bas en haut.
  • Hexadécimal : 1 chiffre hexa = 4 bits. A=10, B=11, C=12, D=13, E=14, F=15.
  • Décimal→hexa : divisions par 16. Ex. 10217 = 27E9₁₆.
  • Octal : 1 chiffre octal = 3 bits.

Réseaux — sous-réseautage (classe C)

Réseau 192.168.28.0 → classe C (privée). Découper en 3 → emprunter 2 bits (2²=4 ≥ 3).

  • Masque : 255.255.255.192 (/26)
  • Sous-réseaux : 4 · Hôtes/sous-réseau : 2⁶−2 = 62
  • Pas d'incrément : 64 → blocs .0 / .64 / .128 / .192
  • 4ᵉ sous-réseau : .192 → hôtes .193 à .254, broadcast .255

Classes : A = 1–126 · B = 128–191 · C = 192–223. Masques par défaut /8, /16, /24.

Architecture des ordinateurs

  • Von Neumann = SISD (Single Instruction Single Data), programme et données en mémoire commune.
  • Mémoire cache : principe de localité de référence (règle 90-10).
  • Hiérarchie mémoire : Registres > Cache > RAM > Disque.
  • Unités : 1 Ko=1024 o, 1 Mo=1024 Ko, 1 Go, 1 To, Po, Eo, Zo, Yo (la plus grande ici).
  • GUI = Graphical User Interface.

UML

  • Cas d'utilisation = acteurs + fonctionnalités. Relations : include, extend, généralisation.
  • Diagramme de classes : classe = attributs + méthodes. Associations avec multiplicités (1, 0..1, 1..*, *).
  • Héritage = flèche triangle vide. Composition = losange plein. Agrégation = losange vide.

Bases de données — passage MCD → relationnel

  • Entité → table, identifiant → clé primaire.
  • Association 1,n → la clé du côté « 1 » migre comme clé étrangère côté « n ».
  • Association n,n → nouvelle table portant les deux clés (clé composée) + attributs de l'association.

SQL — squelette

SELECT cols FROM t1 JOIN t2 ON … WHERE … GROUP BY … HAVING … ORDER BY …

  • Agrégats : COUNT, SUM, AVG, MIN, MAX (souvent avec GROUP BY).
  • Création : CREATE TABLE · Insertion : INSERT INTO · Contraintes : PRIMARY KEY, FOREIGN KEY.

POO (Java / C++)

  • 4 piliers : Encapsulation, Héritage, Polymorphisme, Abstraction.
  • Java : tableau d'entiers → int[] t = new int[5]; · tri → Arrays.sort().
  • Interface : méthodes abstraites (public par défaut), pas d'implémentation (avant Java 8).
  • C++ : classes avec public/private/protected, constructeurs, ::, pointeurs.

PHP · HTML/CSS/Bootstrap

  • PHP : balises <?php ?>, variables $x, superglobales $_GET/$_POST/$_SESSION, echo.
  • HTML : structure sémantique, formulaire <form method>, attribut action.
  • CSS sélecteurs : #id, .classe, balise. Boîte : margin/border/padding/content.
  • Bootstrap : grille container > row > col-* (12 colonnes), classes utilitaires responsives.

La méthode pour réussir en 24 jours

Programme type d'une journée (≈ 6 h)

Deux blocs (matin/après-midi) avec pauses de 10 min toutes les 50 min (méthode Pomodoro).

Bloc 1 — Cours45 minRelire la fiche express + notes du thème du jour

Total ≈ 6 h. Le thème du jour suit l'onglet « Plan J-24 ».

Comment atteindre la maîtrise totale

  • Ne passe au thème suivant qu'une fois le quiz réussi à ≥ 80 % et l'exercice difficile rédigé sans le corrigé.
  • Fais chaque exercice trois fois sur le cycle : découverte → reprise J+3 → contrôle J+7.
  • Chaque niveau compte : commence par les exercices « Facile », finis par « Difficile » avant de valider un thème.
  • Un thème n'est « maîtrisé » que si tu peux refaire l'exercice difficile de mémoire, sans notes.

Les 5 principes

  • Espacement : chaque thème est revu 2 fois (apprentissage puis reprise J+7 à J+10).
  • Test avant tout : se tester fait plus mémoriser que relire.
  • Examens blancs chronométrés (2 h) pour l'endurance et la gestion du temps.
  • Carnet d'erreurs : chaque faute = 1 ligne « question / bonne réponse / pourquoi ».
  • Priorité au rentable : subnetting, SQL, UML et conversions rapportent beaucoup de points sûrs.

Barème mental le jour J

Commence par les QCM et les questions à points sûrs (conversions, réseaux, SQL). Garde les exercices longs (diagramme de classes, code) pour un bloc dédié. Ne laisse aucune case QCM vide s'il n'y a pas de point négatif.
